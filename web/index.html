Wire Protocol

Custom binary framing with a 24-byte header: 4-byte magic DKV1, version, message type, flags, Raft term, payload length, and CRC32 checksum. Falls back to newline-delimited text for plain-socket CLI.

struct MsgHeader {
  uint32_t magic; // 0x444B5631
  uint8_t version;
  uint8_t msg_type;
  uint16_t flags;
  uint64_t term;
  uint32_t length;
  uint32_t checksum; // CRC32
};

Leader Election

Raft-inspired consensus. Followers detect leader failure via UDP heartbeat timeout (randomized 150–300 ms). A candidate broadcasts VOTE_REQ over TCP; first to reach quorum (2/3) wins and immediately sends LEADER_ANNOUNCE.

1HB timeout → CANDIDATE
2Broadcast VOTE_REQ (term+1)
3Collect votes (need ≥ 2)
4Promote → PRIMARY
5Broadcast LEADER_ANNOUNCE

Storage Engine

In-memory hash table (std::unordered_map) protected by std::shared_mutex for concurrent reads. Writes acquire exclusive lock. Supports per-key TTL expiry, atomic DKVSNAP1 snapshots to disk, and a WAL-style replication log.

StorageEngine::
  put(key, val, ttl_sec)
  get(key) → optional<string>
  del(key) → bool
  snapshot() → disk
  restore(path)

Fault Tolerance

The cluster survives any single-node failure. If the PRIMARY crashes, remaining nodes elect a new leader within ~500 ms. Clients are automatically redirected via MOVED host:port. Failed nodes can rejoin as SECONDARY and receive a full state sync.

Nodes failed1 → Operational
Nodes failed2 → Read-only
Nodes failed3 → Cluster Down

Berkeley Sockets

All networking is hand-written using POSIX headers: sys/socket.h, netinet/in.h, arpa/inet.h. No third-party networking libraries. Implements non-blocking connect() via select(), reliable send_all()/recv_all() loops, and TCP + UDP multiplexing.

TCP :8001-8003 (data) UDP :9001-9003 (heartbeats) HTTP :8080 (bridge)
